\# Essentials of Artificial Intelligence





\## Assignments



\### Assignment 1 — AQI Reflex Agent



A rule-based reflex agent that calculates and classifies Air Quality Index (AQI) and provides an appropriate response based on the AQI level.



\*\*Folder:\*\* `Assignment-1-AQI-Reflex-Agent`



\---



\### Assignment 2 — Search Algorithms



Implementation and analysis of different uninformed and informed search algorithms, including applications and comparisons.



\*\*Folder:\*\* `Assignment-2-Search-Algorithms`



\---



\### Assignment 3 — Sleep Score Analysis



A Python-based data analysis project that calculates a Sleep Score using sleep duration, quality of sleep, stress level, physical activity, and sleep disorder information.



The project also provides a rule-based wellbeing interpretation based on Sleep Score and Stress Level.



\*\*Folder:\*\* `Assignment-3-Sleep-Score`
